# Goldin Institute alumni network map (prototype)

A static prototype of the alumni network page: a MapLibre GL map with a Protomaps (OpenStreetMap) basemap, MUI components,
cohort and focus-area filters, a list view, and an apply form (open it directly with `#apply`).

Alumni locations and focus areas are sample data. Map data © OpenStreetMap contributors, Protomaps, Natural Earth, City of Chicago.

- `index.html` — the page
- `overlays.json` — country outlines and Chicago community areas
- `tiles/`, `glyphs/` — basemap tiles and label fonts, stored as base64 text
